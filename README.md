# KV-Cache-Handling-and-Compression

This repository now contains a didactical implementation of autoregressive multi-head attention with an **internal KV cache** (`/home/runner/work/KV-Cache-Handling-and-Compression/KV-Cache-Handling-and-Compression/kv_cache.py`). At each decoding step, the layer appends the new per-head key/value vectors to the cache, then computes attention against the full cached history. This mirrors the inference-time behavior used in transformer decoders: previously computed keys and values are reused instead of recomputed for every token, so each new token only contributes one new KV entry per head.

A simple **KV cache compression** strategy inspired by KVPress `KnormPress` is also included. The `KnormPress` class keeps only the top-`k` keys by L2 norm (per head) and drops the rest, returning statistics about which token indices were kept and excluded. In practice, these stats let you inspect compression behavior (e.g., cache length changing from 4 to 2 and excluded indices like `[0, 2]`), and the tests in `/home/runner/work/KV-Cache-Handling-and-Compression/KV-Cache-Handling-and-Compression/tests/test_kv_cache.py` validate both cache reuse and compression results.
